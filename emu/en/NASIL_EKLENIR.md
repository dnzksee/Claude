# İngilizce sürümü YouTube'a ekleme (Büyük Emu Savaşı)

1. **Başlık ve açıklama:** YouTube Studio → İçerik → videoyu aç → **Altyazılar** → **Dil ekle** → *English* → "Başlık ve açıklama" satırında **Ekle** → `youtube_en.md` içindeki başlığı ve açıklamayı yapıştır → Yayınla.
2. **Altyazı:** Aynı *English* satırında "Altyazılar" → **Ekle** → **Dosya yükle** → "Zamanlamalı" → `altyazi_en.srt` → Yayınla.
3. **Ses parçası:** Aynı *English* satırında "Ses" (Audio) → **Ekle** → `emu_en_ses.mp3` dosyasını yükle → Yayınla.
   Ses dosyası videoyla aynı uzunluktadır (4:52) ve aynı zamanlamayla hizalıdır.
4. Etiketler: `youtube_en.md` içindeki İngilizce etiketleri mevcut etiketlerin sonuna ekleyebilirsin (toplam 500 karakter sınırı).
5. Küçük resim: dile göre küçük resim seçeneği varsa English için kapak_en.png yükle.
